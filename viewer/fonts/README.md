## MgOpen typefaces

# Source and License

https://web.archive.org/web/20050528114140/https://ellak.gr/fonts/mgopen/index.en

# Usage

Use Facetype.js to generate typeface.json fonts: https://gero3.github.io/facetype.js/

Collection of Google fonts as typeface data for usage with three.js: https://github.com/components-ai/typefaces

## Interface fonts (`ui/`)

Inter 4 and JetBrains Mono 2, variable `woff2` files (Latin and Latin Extended)
from the Fontsource packages `@fontsource-variable/inter` and
`@fontsource-variable/jetbrains-mono` 5.3.0, SIL Open Font License 1.1
(`ui/LICENSE-*.txt`). Declared in `viewer/css/fonts.css` as `--font-ui` and
`--font-code`.
