Four things a researcher does with a 3D model

Each tool stores its state in the manifest, under the key shown beneath it. What you set up on screen is what the next reader opens.

Inspect

See the surface, not the texture.

  • Scan viewsOriginal materials, clay, matcap, flat faces, normals, Phong, Lambert, toon, or your own GLSL.modelTransform.shadingMode
  • Raking lightA grazing light that follows the view, for inscriptions and tool marks. Turn it by hand or let it sweep.AIM3DViewer.rakingLight
  • Ambient occlusionCrevices and corners darken so relief reads at a glance.postprocessing.ao
  • Sections and measurementClipping planes on three axes; distance, angle, area, bounding box, surface and volume in real units.AIM3DViewer.clipping

Interpret

Say something about a part of the object.

  • Annotations on facesClick a face, add faces, or drag a rectangle over the visible ones; hidden and cut-away faces are skipped.W3C Web Annotation
  • Level of CertaintyGrade each element of a reconstruction from surveyed fact to hypothesis, and colour the model by it.AIM3DViewer.certainty
  • Guided toursAnnotations become steps with saved camera views, played in order or on their own.viewer.tour
  • HierarchyBrowse the model's parts by name and select whole groups.

Publish

Hand the view on, intact.

  • IIIF manifestsExport and import IIIF Presentation 4 with the AIM3D block: camera, lights, rendering, annotations.IIIF Scene + AIM3DViewer
  • Embed anywhereAn embed configurator writes the snippet; presentation mode hides the editor.viewer.presentationMode
  • Repository integrationA Drupal module for WissKI-based repositories, with metadata shown beside the model.
  • Screenshots and thumbnailsCapture the view, or render gallery thumbnails from nine angles.

Ingest

Bring in what the project already has.

  • Conversion pipelineUploads are unpacked and converted to glTF: Blender for meshes, IfcConvert for BIM, OpenCASCADE for CAD.
  • Compressiongltfpack, Draco, Meshopt and KTX2 textures; a light preview appears first, then the full model.
  • Point cloudsLAS and LAZ load directly; E57 and large scans become streamed 3D Tiles with Eye-Dome Lighting.
  • ArchivesZIP, RAR and tar archives with their textures and material files.

How sure are we about this roof?

A reconstruction mixes what survives with what is inferred. ExPlora4D lets every annotation carry a certainty grade, colours the model by it, and keeps the scale in the manifest so others can read it the same way.

LevelCodeBasisScore
✓APreserved / surveyed10
■BDirect documentation8–9
▲CIndirect sources6–7
≈DAnalogy4–5
?EHypothesis0–3

Each level has a colour, a letter and a symbol, so the scale reads without colour vision and in black-and-white print.

A grade applies to one object or to its whole group. The legend counts assessed objects per level; click a level to show only those parts.

Projects can define their own scale, labels and colours in the manifest; the default above is used otherwise.

The manifest is the view

A IIIF manifest with the viewer's state on board

Standard IIIF carries the scene. The AIM3DViewer block carries what a researcher set up on top of it. Viewers that don't know the block still show the model; ExPlora4D restores the whole reading.

  1. Export from the toolbar after setting up the view.
  2. Validate against the published schema; the viewer checks it on import too.
  3. Share the file or its URL. Opening it restores camera, lights, shading and annotations.
// wolpa-synagogue-aim3d-local-raking-light.json (excerpt)
{
  "type": "Manifest",
  "items": [ { "type": "Scene", … } ],
  "AIM3DViewer": {
    "viewer": {
      "rendering": {
        "toneMapping": "agx",
        "postprocessing": { "enabled": true, "ao": false }
      }
    },
    "rakingLight": {
      "enabled": true,
      "direction": 150,
      "height": 10,
      "sweep": true
    },
    "certainty": { "levels": [ … ] },
    "modelTransform": { "shadingMode": "clay" }
  }
}

Technology

A WebGL viewer in the browser, a conversion worker on the server, and the same code packaged for repositories and phones.

In the browser

  • three.js r186
  • WebGL 2
  • GTAO
  • 3d-tiles-renderer
  • loaders.gl
  • laz-perf
  • web-ifc
